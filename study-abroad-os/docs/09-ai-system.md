# AI System

## AI can
- extract structured fields from official pages/PDFs
- normalize naming and requirements
- summarize complex requirements
- explain eligibility results
- recommend options using structured data
- generate personalized application journeys
- help users understand documents and next actions

## AI must not be the sole authority for
- official deadlines
- visa rules
- tuition
- legal requirements
- scholarship eligibility/benefits

## Principle
AI explains; official sources verify.

## MVP AI priority
Use AI behind the scenes for data processing and explanation before building a prominent generic chatbot.
