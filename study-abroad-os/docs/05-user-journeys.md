# Core User Journeys

## Main journey
Explore -> Create Profile -> Discover Universities/Scholarships -> Check Eligibility -> Shortlist -> Start Application -> Complete Documents/Deadlines -> Submit -> Offer -> Visa/Housing/Travel -> Community -> Arrival.

## Help journey
User gets stuck -> Contextual AI help -> Still unresolved -> Request human help -> Match verified senior by university/scholarship/skill/language -> Book session -> Rate outcome.

## Mentor lifecycle
Student uses platform -> studies abroad -> becomes verified current student/alumni -> opts into mentor supply -> helps newer students -> earns income -> strengthens network.

## Community lifecycle
Applicant -> admitted -> current student -> alumni/mentor.

## Housing journey (later)
Offer/pre-departure -> select university -> browse nearby verified housing -> compare rent/deposit/utilities/commute -> inspect trust signals/reviews -> contact/book through supported safe flow -> report issues.
