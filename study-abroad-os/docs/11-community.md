# Community

## Role
Community is not a general social network. It is a utility and trust layer tied to the study-abroad journey.

## Core organization
Country -> University -> Intake -> optional Program/Nationality groups.

## Example user statuses
- Applicant
- Admitted
- Current Student
- Alumni

## Core jobs
- ask university-specific questions
- find students in the same intake
- connect with same-language/same-nationality peers
- get advice from current students/alumni
- later support roommate/travel-buddy discovery with appropriate safeguards

## MVP approach
Community lite: membership, basic threads/chat, verification signals, report/block/moderation. No general algorithmic social feed.
