# L01: เตรียม runbook และ rehearsal ก่อน deploy

TASK ID: L01
ชื่อสั้นของงาน: เตรียม runbook และ rehearsal ก่อน deploy
ประเภท: deployment-preparation
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
เตรียม runbook และ rehearsal ก่อน deploy เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. release owner ตรวจ environment names เท่านั้น: staging แยก DB จาก production; ไม่มี secret ในเอกสารหรือ prompt
2. rehearse additive migrations/seed บน disposable DB ที่มี legacy fixtures; ทำสองครั้งและตรวจ row/history counts
3. บันทึก backup/restore verification และ last-good deploy ID ผ่าน owner ที่มีสิทธิ์; migration ต้องเสร็จก่อน deploy เพราะ B03
4. ระบุขั้นตอน staging publish/review, production migration/deploy, cron history check, smoke และ rollback trigger

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.
งานนี้เน้นเอกสาร/หลักฐาน/ตรวจรับ; ห้ามแก้ application code เว้นแต่ write allowlist ระบุไว้.

Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.

## Acceptance Criteria
- [ ] runbook มีคำสั่งที่รันได้จริงจาก candidate พร้อม expected outcome และ halt points
- [ ] rollback frontend ไม่สมมติว่า rollback DB อัตโนมัติ; ไม่ลบ schema ใหม่

- [ ] go-live ห้ามผ่านหาก backup/owner/staging isolation ยังไม่ยืนยัน
- [ ] diff อยู่ใน allowlist; prerequisite version ถูกต้อง; รายงานแยก PASS/FAIL/NOT_RUN และขอ READY_FOR_REVIEW.
