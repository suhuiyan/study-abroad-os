# B03: แยก seed ออกจาก build และป้องกันทับข้อมูลที่ตรวจแล้ว

TASK ID: B03
ชื่อสั้นของงาน: แยก seed ออกจาก build และป้องกันทับข้อมูลที่ตรวจแล้ว
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
แยก seed ออกจาก build และป้องกันทับข้อมูลที่ตรวจแล้ว เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. แยก additive schema migration และ seed เป็นคำสั่งชัดเจน; build ปกติไม่เขียน DB
2. bootstrap program เฉพาะ ID ใหม่ด้วย ON CONFLICT DO NOTHING; การแก้รายการที่มีแล้วต้องผ่าน review/publish
3. ทดสอบ deploy/seed ซ้ำหลัง admin แก้ข้อมูล รวมกรณี checkedAt เท่ากัน/ต่างกัน
4. เขียนลำดับ migration-before-deploy และ rollback แบบคงข้อมูลสำหรับ L01; อย่าไปเปลี่ยน Vercel settings ในงานนี้

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.


## บริบทที่จำเป็น
เป้าหมายผู้ใช้: นักเรียนไทยสมัครปริญญาตรีจีน. สิบรายการปัจจุบันเป็นสิบเส้นทางตั้งต้น ไม่ใช่ทุกสาขา.
Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.
เหตุผลจาก baseline/ความเสี่ยงที่ต้องจัดการ: seed เดิมใช้ checkedAt เป็นเงื่อนไข update จึงอาจข้ามการแก้หรือทับ admin; แยก bootstrap กับ publication ให้ตรวจได้
