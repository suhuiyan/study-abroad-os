# B01: ล็อกข้อกำหนดข้อมูลและขอบเขตรอบส่งมอบ

TASK ID: B01
ชื่อสั้นของงาน: ล็อกข้อกำหนดข้อมูลและขอบเขตรอบส่งมอบ
ประเภท: planning
สถานะ: ACCEPTED (contract 1.0 ใน reports/B01.md)

## เป้าหมาย
ล็อกข้อกำหนดข้อมูลและขอบเขตรอบส่งมอบ เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. ตรวจ baseline commit และอ่าน proposed contract; บันทึกสิ่งที่ยืนยันจากโค้ดแยกจากนโยบายที่เสนอ
2. กำหนด field provenance, intake year/month/round, scholarship scope, unknown reasons และ rule applicability แบบ backward compatible
3. กำหนดค่า default: คิวให้ผู้ดูแลอ่านต้นฉบับและแก้ draft เอง; source changed ห้ามเผยแพร่อัตโนมัติ; ไม่เพิ่ม AI provider
4. กำหนด stale policy เป็น configuration ที่เสนอพร้อมเหตุผล และบันทึกชื่อผู้ที่จะตรวจรับข้อมูล/ทำ release ว่ายังต้องระบุ

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.
งานนี้เน้นเอกสาร/หลักฐาน/ตรวจรับ; ห้ามแก้ application code เว้นแต่ write allowlist ระบุไว้.

## บริบทที่จำเป็น
เป้าหมายผู้ใช้: นักเรียนไทยสมัครปริญญาตรีจีน. สิบรายการปัจจุบันเป็นสิบเส้นทางตั้งต้น ไม่ใช่ทุกสาขา.
Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.
เหตุผลจาก baseline/ความเสี่ยงที่ต้องจัดการ: ข้อกำหนดคลุมเครือทำให้หลาย Agent ตีความต่างกัน; reviewer ตรวจตัวอย่าง unknown และหลายรอบสมัครก่อนรับงาน
เป็น task เริ่มต้น; ใช้ baseline evidence และเสนอ contract ที่ explicit โดยแยกสิ่งที่ยังต้องตัดสินใจ.
