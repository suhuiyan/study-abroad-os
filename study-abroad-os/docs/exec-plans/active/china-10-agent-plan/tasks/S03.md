# S03: เพิ่มตารางคิวตรวจทานและสถานะรัน

TASK ID: S03
ชื่อสั้นของงาน: เพิ่มตารางคิวตรวจทานและสถานะรัน
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
เพิ่มตารางคิวตรวจทานและสถานะรัน เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. เพิ่ม additive tables source_check_run และ review_item พร้อม source_id/hash/program_id/base_revision/status/payload/reviewer/time
2. เพิ่ม uniqueness ของหนึ่ง event source+hash+program; lifecycle pending -> draft -> approved/rejected; approved terminal
3. เก็บ before/after payload และ baseline revision เพื่อป้องกัน concurrent publish
4. ทดสอบ migrate สองครั้งบน DB ทิ้งได้ โดยเก็บ programs/source_version เดิม

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.

Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.

- [ ] เพิ่มตารางไม่แก้ ID หรือ body ของ source_version เดิม
- [ ] state contract ตรวจ enum/invalid transitions ได้
