# S04: เชื่อมการตรวจรายวันกับคิวแบบไม่เผยแพร่อัตโนมัติ

TASK ID: S04
ชื่อสั้นของงาน: เชื่อมการตรวจรายวันกับคิวแบบไม่เผยแพร่อัตโนมัติ
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
เชื่อมการตรวจรายวันกับคิวแบบไม่เผยแพร่อัตโนมัติ เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. sync จาก active registry พร้อม identity ของ S01; เก็บ run summary success/error count กับเวลาจบ
2. source hash เปลี่ยนสร้าง pending item ต่อ affected program; same hash ไม่สร้างใหม่; first fetch ติดป้าย baseline
3. ใช้ DB lease/advisory lock กัน run ซ้อนและ time budget พร้อม deferred list ก่อนหมด 300s
4. errors ไม่ลบ last-known-good data; ทุกการ fetch ห้ามเขียน program.data

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.

เป้าหมายผู้ใช้: นักเรียนไทยสมัครปริญญาตรีจีน. สิบรายการปัจจุบันเป็นสิบเส้นทางตั้งต้น ไม่ใช่ทุกสาขา.
Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.
เหตุผลจาก baseline/ความเสี่ยงที่ต้องจัดการ: ความเปลี่ยนของ HTML อาจเป็น navigation; admin ต้องอ่าน diff ก่อน update

- [ ] run ซ้ำและพร้อมกันไม่สร้าง duplicate snapshot/queue
- [ ] ไม่มี secret=503, bad token=401; test ใช้ค่าเทียม
- [ ] ไม่มีการแก้ deadline/ทุนอัตโนมัติ; cron schedule เดิมคงอยู่และระบุเป็น daily polling
