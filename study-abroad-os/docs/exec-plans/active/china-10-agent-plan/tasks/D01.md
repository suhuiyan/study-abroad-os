# D01: เพิ่ม provenance และรอบสมัครแบบเข้ากับข้อมูลเดิม

TASK ID: D01
ชื่อสั้นของงาน: เพิ่ม provenance และรอบสมัครแบบเข้ากับข้อมูลเดิม
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
เพิ่ม provenance และรอบสมัครแบบเข้ากับข้อมูลเดิม เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. เพิ่ม schema optional สำหรับ provenance ราย field และรอบปี/เดือน/รอบย่อย โดยไม่เปลี่ยน ID เดิม
2. เพิ่ม scholarship applicability/provenance และ unknown reason ตาม contract
3. parse records เก่าให้ทำงานเดิมได้; round ที่ไม่ยืนยันห้ามคำนวณเป็น open
4. เพิ่ม schema tests ของ malformed dates, ข้อขัดแย้ง, ไม่มี source และ record เก่า

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.
