TASK ID: A02

ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
ทำ API เตรียม draft จากหลักฐานที่ตรวจแล้ว เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. เพิ่ม create/update draft โดยเก็บ base revision ก่อนแก้ และ reference evidence
2. รองรับ draft จาก source change และ manual correction ตาม manifest D02
3. ตรวจ programSchema และ critical field evidence server-side; disallow mutation ของ approved item
4. ตอบ 400 malformed,403 permission,409 stale draft; ไม่เขียน program จนอนุมัติ

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.


## บริบทที่จำเป็น
เป้าหมายผู้ใช้: นักเรียนไทยสมัครปริญญาตรีจีน. สิบรายการปัจจุบันเป็นสิบเส้นทางตั้งต้น ไม่ใช่ทุกสาขา.
Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.
เหตุผลจาก baseline/ความเสี่ยงที่ต้องจัดการ: draft เผยแพร่ก่อนตรวจรับ; แยก write store และ status gate
