## เป้าหมาย
ผูกภาษาและวุฒิกับกฎที่มีหลักฐาน เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. อ่าน verified rules ของ D01 และแยก publication-year applicability
2. ตรวจ HSK ระดับ/คะแนน IELTS รวม/รายทักษะกับกรณียกเว้น; ระดับ HSK สูงกว่าไม่เทียบคะแนนต่างระดับเอง
3. ตรวจ qualification เฉพาะ rule ที่ยืนยัน; other/foundation/unknown ไม่ auto-pass และไม่แปลง GPA scale เอง
4. แยก unfilled, insufficient score, unknown university criterion พร้อม field evidence

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.

## Acceptance Criteria
- [ ] ครบ fixtures absent/below/equal/above threshold และ exception unknown
- [ ] rule ปีเก่าไม่ให้ pass สำหรับปีใหม่
- [ ] qualifications รองรับ evidence ที่มี; กรณีไม่มี rule ส่ง needs-review
- [ ] overall preliminary pass ได้เฉพาะ required criteria ที่รู้ครบ; ไม่รับรอง admission
- [ ] diff อยู่ใน allowlist; prerequisite version ถูกต้อง; รายงานแยก PASS/FAIL/NOT_RUN และขอ READY_FOR_REVIEW.
