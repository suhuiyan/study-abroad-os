# E04: แสดงผล eligibility และ freshness ที่ตรงกับหลักฐาน

TASK ID: E04
ชื่อสั้นของงาน: แสดงผล eligibility และ freshness ที่ตรงกับหลักฐาน
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
แสดงผล eligibility และ freshness ที่ตรงกับหลักฐาน เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. เพิ่ม optional CSCA inputs ตาม E03 และคง form fields เดิม
2. แสดง unknown/gap/preliminary checks พร้อมเหตุผลและ source ต่อ field; ตรวจรุ่นข้อมูลและ round ที่ใช้
3. แยก fetchedAt กับ verifiedAt เท่าที่ API มี; ค่าไม่มีห้ามแสดงเป็นวันนี้
4. แก้ label ปิดรอบ 2026 ที่ hardcode ให้ derive จาก record และแสดง service error อย่างชัดเจนเมื่อ catalog fallback

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.
