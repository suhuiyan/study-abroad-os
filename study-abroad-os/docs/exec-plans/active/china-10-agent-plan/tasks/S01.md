# S01: ทำ source ID ให้คงที่และรักษาประวัติ

TASK ID: S01
ชื่อสั้นของงาน: ทำ source ID ให้คงที่และรักษาประวัติ
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
ทำ source ID ให้คงที่และรักษาประวัติ เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. เปลี่ยนการสร้าง ID ตามลำดับ array ให้เป็น identity ที่คงที่ตาม canonical URL; export เดิมยังใช้ได้
2. ตรวจ URL normalization แบบไม่ตัด query ที่มีความหมาย
3. สำหรับ row เก่า lookup ด้วย URL และคง existing ID; ไม่ย้าย source_version ไป URL ใหม่
4. ทดสอบ reorder/add/remove URL และ duplicate URL ใน DB ทิ้งได้

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.


## บริบทที่จำเป็น
เป้าหมายผู้ใช้: นักเรียนไทยสมัครปริญญาตรีจีน. สิบรายการปัจจุบันเป็นสิบเส้นทางตั้งต้น ไม่ใช่ทุกสาขา.
Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.
เหตุผลจาก baseline/ความเสี่ยงที่ต้องจัดการ: ID ตามตำแหน่งเดิมเสี่ยงประวัติสลับมหาวิทยาลัย; ใช้ URL identity และคง legacy mapping
