สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
รวมข้อมูลที่ผ่าน review เข้า catalog ชุดแรก เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. เทียบ verdict กับ record เดิมทีละมหาวิทยาลัย; เปลี่ยนเฉพาะค่าที่ผ่าน review และเก็บ unresolved เป็น unknown
2. คง 10 program IDs และ universityIds; รอบใหม่เป็นข้อมูลมีหลักฐาน ไม่เพิ่ม all-program coverage
3. แนบ field provenance ตาม D01 และตั้ง verifiedAt เฉพาะที่มีผู้ตรวจรับ
4. ทดสอบ catalog/provenance/schema และส่ง before-after manifest สำหรับ A02 สร้าง draft; การ deploy seed จะไม่ update row เดิมตาม B03

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.


## บริบทที่จำเป็น
เป้าหมายผู้ใช้: นักเรียนไทยสมัครปริญญาตรีจีน. สิบรายการปัจจุบันเป็นสิบเส้นทางตั้งต้น ไม่ใช่ทุกสาขา.
Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.
เหตุผลจาก baseline/ความเสี่ยงที่ต้องจัดการ: catalog ใน Git กับ DB ไม่ตรง; ส่ง manifest ให้เข้าคิว publication ไม่ใช้ seed overwrite
ต้องอ่านผลที่ผ่านตรวจของ D01, S01, V01, V02, V03, V04, V05 ก่อนลงมือ. ไฟล์ใหม่ใน read list จะเกิดจาก dependency; ห้ามสมมติว่ามีแล้วใน baseline.
