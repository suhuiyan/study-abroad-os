# Q05: ตรวจรับ candidate แบบอิสระ

TASK ID: Q05
ชื่อสั้นของงาน: ตรวจรับ candidate แบบอิสระ
ประเภท: review
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
ตรวจรับ candidate แบบอิสระ เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. reviewer ตรวจ diff ของ candidate commit เทียบ baseline และ trace ทุก changed critical value ไป evidence
2. ตรวจ no-regression ของ auth/search/shortlist/plan และผล integration/e2e ล่าสุดที่ตรง candidate
3. ตรวจ issue จาก usability ทุก blocker มี bounded fix task/หลักฐาน retest; ห้ามรวมแก้ทุกปัญหาในใบงาน review นี้
4. ส่ง go/no-go พร้อม residual unknown รายมหาวิทยาลัยและ rollback conditions

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.
งานนี้เน้นเอกสาร/หลักฐาน/ตรวจรับ; ห้ามแก้ application code เว้นแต่ write allowlist ระบุไว้.

## บริบทที่จำเป็น
เป้าหมายผู้ใช้: นักเรียนไทยสมัครปริญญาตรีจีน. สิบรายการปัจจุบันเป็นสิบเส้นทางตั้งต้น ไม่ใช่ทุกสาขา.
Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.
เหตุผลจาก baseline/ความเสี่ยงที่ต้องจัดการ: ผล tests เก่าบนคนละ commit ทำให้ตัดสินปล่อยผิด; pin candidate SHA
ต้องอ่านผลที่ผ่านตรวจของ Q04 ก่อนลงมือ. ไฟล์ใหม่ใน read list จะเกิดจาก dependency; ห้ามสมมติว่ามีแล้วใน baseline.
