# P01: แก้ปีเป้าหมายและการอัปเดตสถานะใบสมัคร

TASK ID: P01
ชื่อสั้นของงาน: แก้ปีเป้าหมายและการอัปเดตสถานะใบสมัคร
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
แก้ปีเป้าหมายและการอัปเดตสถานะใบสมัคร เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. start รับ targetIntake ที่ validate หรือใช้ profile ของ session ตาม contract ไม่ hardcode 2027
2. คงหนึ่ง application ต่อ user/program สำหรับรอบนี้; เมื่อมีอยู่แล้ว return existing ID และไม่ทับ notes/tasks
3. เพิ่ม mutation สถานะ preparing/submitted/offer/closed โดย server validate; intake confirmation ไม่แปลว่ามหาวิทยาลัยเปิดรอบนั้น
4. แยก invalid JSON=400 กับ backend failure=503 พร้อมทดสอบ ownership user A/B

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.


## บริบทที่จำเป็น
เป้าหมายผู้ใช้: นักเรียนไทยสมัครปริญญาตรีจีน. สิบรายการปัจจุบันเป็นสิบเส้นทางตั้งต้น ไม่ใช่ทุกสาขา.
Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.
เหตุผลจาก baseline/ความเสี่ยงที่ต้องจัดการ: เปลี่ยนปีใบสมัครเดิมทำให้ checklist สับสน; return existing และ require explicit update
ต้องอ่านผลที่ผ่านตรวจของ A03, E03 ก่อนลงมือ. ไฟล์ใหม่ใน read list จะเกิดจาก dependency; ห้ามสมมติว่ามีแล้วใน baseline.
