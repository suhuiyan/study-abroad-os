# S02: จำกัดการดาวน์โหลดและแยก error ของแต่ละแหล่ง

TASK ID: S02
ชื่อสั้นของงาน: จำกัดการดาวน์โหลดและแยก error ของแต่ละแหล่ง
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
จำกัดการดาวน์โหลดและแยก error ของแต่ละแหล่ง เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. แยก fetch helper สำหรับใช้ fake responses ใน test
2. อ่าน response เป็น stream และยกเลิกทันทีเมื่อเกิน 4 MiB แม้ไม่มี content-length; จำกัด timeout และ redirect
3. บันทึก HTTP status ล่าสุดของ error, content type ที่รับ และ failure reason แบบไม่รวม secret
4. ไม่แทน latest good snapshot ด้วย timeout/error HTML; จำกัด accepted HTML/PDF; บันทึกหน้าที่ต้องตรวจแทนพยายาม bypass bot protection

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.
