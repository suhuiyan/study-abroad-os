# Q02: ทดสอบเส้นทางนักเรียนและผู้ดูแลบน browser

TASK ID: Q02
ชื่อสั้นของงาน: ทดสอบเส้นทางนักเรียนและผู้ดูแลบน browser
ประเภท: testing
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
ทดสอบเส้นทางนักเรียนและผู้ดูแลบน browser เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. เพิ่ม browser test runner เฉพาะ dev dependencies และ test:e2e; local/staging fixture server เท่านั้น
2. นักเรียน: login -> profile -> search -> details -> eligibility -> save -> plan -> task/status/note -> reload
3. admin: source queue -> draft -> source link -> approve -> student sees change; non-admin direct navigation forbidden
4. ตรวจ 1280x800 และ 390x844 screenshots, visible overflow, dialog focus/Escape, console errors และ failure/conflict views

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.


## บริบทที่จำเป็น
เป้าหมายผู้ใช้: นักเรียนไทยสมัครปริญญาตรีจีน. สิบรายการปัจจุบันเป็นสิบเส้นทางตั้งต้น ไม่ใช่ทุกสาขา.
Baseline ที่ตรวจ: 630a2b1; coordinator ต้องส่ง BASE_COMMIT ที่รวม dependencies แล้วในวันเริ่มงาน.
เหตุผลจาก baseline/ความเสี่ยงที่ต้องจัดการ: UI ผ่านแต่ persistence fail; assert API-backed state หลัง reload
