# A03: ทำ atomic publish และปิดช่อง bypass ของ admin เดิม

TASK ID: A03
ชื่อสั้นของงาน: ทำ atomic publish และปิดช่อง bypass ของ admin เดิม
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
ทำ atomic publish และปิดช่อง bypass ของ admin เดิม เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. publish ใน transaction: lock item/program, ตรวจ expected base revision, validate evidence, เขียน program_revision และ program แล้ว mark approved
2. ห้ามเผยแพร่ item เดิมซ้ำ; กรณี conflict ตอบ 409 พร้อมให้ re-review
3. แก้ action program เดิมให้สร้าง draft หรือปฏิเสธการ publish ตรงตาม contract เพื่อไม่มี bypass
4. ทดสอบ actor audit และ rollback เมื่อ revision write ล้มเหลว

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.
