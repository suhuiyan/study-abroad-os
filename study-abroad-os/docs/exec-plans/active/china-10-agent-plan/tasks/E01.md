# E01: แก้การเทียบปีและอายุผลสอบให้มีขอบเขตชัด

TASK ID: E01
ชื่อสั้นของงาน: แก้การเทียบปีและอายุผลสอบให้มีขอบเขตชัด
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
แก้การเทียบปีและอายุผลสอบให้มีขอบเขตชัด เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. แทน intake.includes ด้วย exact normalized year/month/round matching; missing year=unknown
2. แยก date-only deadline จาก exact datetime; ใช้ timezone ของหลักฐาน
3. validity คิดตาม reference date ที่ประกาศกำหนด; ถ้าไม่ทราบวันอ้างอิงห้าม pass ที่สื่อว่าครอบคลุมวันสมัคร
4. เพิ่ม tests วันเปลี่ยนปี leap day ผลสอบอนาคต วันหมดอายุ ปีว่าง และ 2026 เทียบ 2027

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.
