# P03: เพิ่มสถานะใบสมัครและบันทึก notes อย่างทนต่อความผิดพลาด

TASK ID: P03
ชื่อสั้นของงาน: เพิ่มสถานะใบสมัครและบันทึก notes อย่างทนต่อความผิดพลาด
ประเภท: coding
สถานะ: PLANNED (ใบงานนี้ยังไม่ได้ดำเนินการ)

## เป้าหมาย
เพิ่มสถานะใบสมัครและบันทึก notes อย่างทนต่อความผิดพลาด เพื่อให้ส่วนงานนี้ตรวจรับได้ตามเกณฑ์ด้านล่างและส่งต่อให้ task ที่พึ่งพา โดยใช้ระบบ MVP เดิม.

## ขอบเขต
1. เพิ่มตัวเลือก intake ตอนเริ่มและ status selector; ส่ง expectedVersion ทุก mutation
2. เก็บ notes draft แยกจาก workspace reload พร้อม save state/error/retry; ถ้า conflict รักษาข้อความ draft
3. แยก due ที่ผู้ใช้ตั้งเองจาก official deadline; ไม่ใช้ทุน deadline เป็น admission deadline
4. ทดสอบ notes + checkbox เร็ว ๆ, slow network, reload หลังบันทึก และเปลี่ยนหน้าเมื่อมี draft

## นอกขอบเขต
ไม่แก้เรื่องอื่นใน roadmap, ไม่ refactor ทั้งแอป, ไม่เปลี่ยน provider/architecture, ไม่เพิ่มมหาวิทยาลัยเกินชุดแรก.
ไม่เข้าหรือแก้ production, ไม่ push main/deploy, ไม่อ่านหรือขอ production secrets.

## Acceptance Criteria
- [ ] note ไม่หายเมื่อ request อื่นเสร็จหรือบันทึก fail
- [ ] status/intake/progress/date แสดงหลัง reload ตรง server
- [ ] conflict เห็นชัดและมีทางโหลดค่าล่าสุดโดยไม่ทิ้ง draft เงียบ ๆ
- [ ] mobile keyboard ใช้งาน date/status/note ได้
- [ ] diff อยู่ใน allowlist; prerequisite version ถูกต้อง; รายงานแยก PASS/FAIL/NOT_RUN และขอ READY_FOR_REVIEW.

dependency artifact ไม่พบ, contract ขัดแย้ง, ต้องแก้ไฟล์นอก allowlist หรือ test ต้องใช้ production: หยุดส่วนที่พึ่งเงื่อนไขนั้นและส่ง BLOCKED/NEEDS_DECISION พร้อม reproduction และทางเลือกเล็กที่สุด.
