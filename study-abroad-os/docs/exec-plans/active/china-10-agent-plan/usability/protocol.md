# Study Abroad OS Usability Protocol

สถานะ: protocol พร้อมใช้ แต่ยังไม่ใช่ผลการทดสอบผู้ใช้จริง

## ผู้เข้าร่วม

- นักเรียนไทย 5 คนที่กำลังเรียน ม.ปลายหรือเพิ่งจบและสนใจปริญญาตรีจีน
- ใช้รหัส P01-P05 แทนชื่อ ห้ามเก็บเลขหนังสือเดินทาง คะแนนจริง หรือข้อมูลสุขภาพ
- เจ้าของโครงการเป็นผู้เชิญและขอ consent ว่าอนุญาตให้จดพฤติกรรมและคำพูดแบบไม่ระบุตัวตน

## การเตรียม

- ใช้ staging/test account และข้อมูลสังเคราะห์เท่านั้น
- ให้ persona: เป้าหมายเข้าเรียน 2027, สนใจธุรกิจ, IELTS 5.5, ยังไม่มี CSCA
- ผู้สังเกตไม่อธิบาย navigation หรือความหมายของป้ายก่อนเริ่ม

## งานทดสอบ 7 งาน

1. ค้นหาหลักสูตรธุรกิจภาษาอังกฤษในปักกิ่ง และบอกว่าพบกี่รายการ
2. เปิดหน้าทุน แล้วแยกวันปิดทุนออกจากวันปิดรับสมัครมหาวิทยาลัย
3. กรอกโปรไฟล์ด้วยข้อมูล persona โดยไม่ใส่ข้อมูลจริงของผู้เข้าร่วม
4. เปิดรายละเอียดหนึ่งรายการ แล้วอธิบายว่าเงื่อนไขใด “ไม่ผ่าน” และเงื่อนไขใด “ยังไม่ทราบ”
5. เปิดลิงก์หลักฐานทางการของเงื่อนไขอย่างน้อยหนึ่งรายการ
6. บันทึกตัวเลือก แล้วกลับมาหาจากหน้า “ที่บันทึก”
7. สร้าง Application Plan ปี 2027 เปลี่ยนสถานะ ทำ checklist หนึ่งข้อ ใส่โน้ต แล้ว reload เพื่อตรวจว่าข้อมูลยังอยู่

## Observer Prompts

- เริ่มด้วย “ลองทำตามโจทย์โดยคิดออกเสียงได้เลย”
- ถ้าหยุดเกิน 60 วินาที ถามเพียง “ตอนนี้กำลังมองหาอะไร”
- ห้ามชี้ตำแหน่งปุ่มหรือให้คำตอบ จนผู้เข้าร่วมประกาศว่ายอมแพ้
- หลังแต่ละงานถาม “อะไรทำให้มั่นใจหรือไม่มั่นใจ”

## การให้คะแนน

- `2` ทำสำเร็จเองโดยไม่มีคำใบ้
- `1` สำเร็จหลังคำถามกลาง ๆ หรือหลงทางแล้วกลับมาได้
- `0` ทำไม่สำเร็จ ต้องให้ผู้สังเกตกดแทน หรือเข้าใจผลตรงข้าม
- Critical misunderstanding: เข้าใจ unknown ว่าผ่าน, ใช้ deadline ทุนเป็น deadline สมัครเรียน, หรือคิดว่าผลเบื้องต้นคือการรับรอง admission

เกณฑ์ผ่านก่อน release: อย่างน้อย 4/5 คนจบงาน 1, 3, 4, 6, 7 โดยไม่มีคนกดแทน และไม่มี critical misunderstanding ที่ยังไม่แก้

## Dry Run Simulation

ทำ walkthrough ด้วย persona สังเคราะห์หนึ่งรอบเพื่อเช็ก wording และลำดับงานเท่านั้น ผลนี้ห้ามนับเป็นผู้เข้าร่วมจริง

## การจัดประเภทสิ่งที่พบ

- Bug: พฤติกรรมผิดจาก contract หรือข้อมูลไม่คงอยู่หลัง reload
- Content issue: ข้อมูล/หลักฐานขาด ขัดกัน หรือติดป้ายเกินจริง
- Usability issue: ระบบทำงานแต่ผู้ใช้หาไม่พบหรือเข้าใจผิด
- New feature: ความต้องการใหม่ที่ไม่ขัดขวาง core flow; แยก backlog ห้ามรวมเป็น bug
