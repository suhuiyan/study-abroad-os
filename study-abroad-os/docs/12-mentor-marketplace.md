# Student Mentor Marketplace

## Concept
Software is the default. Human help is available on demand when a student gets stuck.

## Mentor matching signals
- same university
- same scholarship experience
- same country
- same language/nationality when useful
- relevant skills (application, scholarship, visa preparation, housing, campus life)

## Core flow
Request help -> categorize problem -> match mentors -> view verification/skills/rating -> book -> session -> outcome rating/review.

## Mentor boundaries
Mentors may explain personal experience, help organize checklists, review completeness, and share practical knowledge. They must not guarantee admission/scholarships, impersonate institutions, request account passwords, or present regulated legal/immigration advice unless appropriately qualified.

## Validation approach
Start as a concierge/manual matching service with a small verified mentor pool before building a full marketplace.
